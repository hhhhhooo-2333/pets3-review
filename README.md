# PETS3 复习舱

这是已经整理好的 GitHub Pages 静态网站版本，包含：

- 1110 个单词及复习、测试、错词功能
- 13 套历年试卷和答案解析
- 10 套听力 MP3
- 学习技巧和自定义知识点
- 手机自适应和添加到主屏幕功能

## 发布方法

1. 安装并登录 GitHub Desktop。
2. 选择 `File` -> `New repository`，仓库名填写 `pets3-review`。
3. 将本文件夹中的全部内容复制到新仓库根目录。
4. 在 GitHub Desktop 中填写提交说明，例如 `Initial PETS3 review site`。
5. 点击 `Commit to main`，然后点击 `Publish repository`。
6. 在 GitHub 仓库网页进入 `Settings` -> `Pages`。
7. Source 选择 `Deploy from a branch`，Branch 选择 `main` 和 `/(root)`，然后保存。
8. 等待几分钟后访问 `https://你的用户名.github.io/pets3-review/`。

## 注意

- 免费 GitHub Pages 通常需要公开仓库，上传前请确认你有权公开其中的试卷和音频。
- 本项目仅供个人学习使用，与 PETS 官方机构无关。
- 学习记录存放在每台设备的浏览器中，不会自动跨设备同步。
